# Phase 2 filtered-universe Parquet catalog

The filtered Phase 2 analytical universe (`data/processed/phase2-filtered/`, gitignored,
regenerated by `scripts/23_build_filtered_phase2_extracts.py`) restricts every rating-bearing
extract to the **16,627-game research population** (`data/processed/bgg_research_population.parquet`,
built by `scripts/01_clean_population.py`). It is the primary input layer for subsequent
quality/taste/hidden-gem work. The full-snapshot extracts under `data/processed/phase2/` remain
untouched as historical reference (see the archived `archive/phase3-full-snapshot-2026-08-24`
branch for why they were superseded).

Filtering uses explicit SEMI JOINs on `game_id`, so rows are neither duplicated nor dropped; the
canonical observation definition from `scripts/13`/`14` is unchanged (every non-null review
rating, no deduplication, source keys retained). Machine-readable counts: regenerate with
`scripts/23` and read `data/processed/phase2-filtered/parquet_catalog.csv` + `validation.json`.

## Observed facts from the filtering run (2026-08-24)

- **94.1% of all rating observations fall on population games [Observed fact]:** popularity
  concentration means the excluded ~79k low-volume games hold only ~1.59M observations.
- **16,567 of 16,627 population games have ≥1 rating in the SQLite snapshot [Observed fact]:**
  the 60 missing titles are recent high-game_id releases absent from this earlier scrape
  (examples: Orloj: The Prague Astronomical Clock, Covenant). Snapshot mismatch, not a filter loss.
- **Only 13,449 of the 16,567 rated population games (81.2%) have a `games.parquet` metadata row
  [Observed fact]:** `game_attrs` covers 21,925 of the 95,540 snapshot games, so attrs-based
  analyses (weight, player counts) will not cover ~19% of rated population games. The
  game-level population parquet remains the complete metadata source for all 16,627.
- **Validations passed:** output row count equals an independent count of the unfiltered source
  restricted to population games (no duplication/drop); 0 filtered ratings lack a `users` row;
  deterministic collection triple-join sample matched 2,567/2,567; per-game spot checks match the
  findings.md record exactly (Brightcast 5, Evil Upheaval 140, Goblin Grapple 209, Grasse 111,
  Abuela Co. 66); repeated user-game pairs preserved (1,465 pairs / 3,022 observations).
- Sub-1.0 junk ratings exist in the source (18 rows full snapshot, 9 within the population) and
  are preserved as-is under the no-modification policy.

## Reproduce

```bash
python scripts/23_build_filtered_phase2_extracts.py \
    --input-dir data/processed/phase2 \
    --population data/processed/bgg_research_population.parquet
```

In worktrees without local base extracts, point `--input-dir` at the copied extracts
(e.g. `scratch/phase2`); see `data/processed/phase2-filtered/README.md` (generated) for the exact
invocation used for the current outputs.
