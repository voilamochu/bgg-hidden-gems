# Phase 2 active-universe Parquet catalog

The active Phase 2 analytical universe (`data/processed/phase2-active/`, gitignored,
regenerated by `scripts/24_build_active_phase2_extracts.py`) restricts the
16,627-game research population (`data/processed/bgg_research_population.parquet`,
built by `scripts/01_clean_population.py`) to **active users**: `cnt_filtered ≥10`
ratings within that universe (t=10 primary, `scripts/23_user_threshold_study.py`),
minus 667 `degenerate_strict` users (n≥20 AND single-value OR SD<0.2 OR modal≥95%
on ROUND-binned ratings, `scripts/25`), treated as low-information / degenerate noise.
It is the primary input layer for subsequent quality/taste/hidden-gem work.
`degenerate_broad` is preserved as `is_degenerate_broad` for sensitivity analysis.

Filtering uses explicit SEMI JOINs on `game_id` + `user_pseudouserid`, so rows are
neither duplicated nor dropped; the canonical observation definition from
`scripts/13`/`14` is unchanged (every non-null review rating, no deduplication,
source keys retained). Full-snapshot extracts under `data/processed/phase2/` remain
untouched as historical reference; `data/processed/phase2-filtered/` (16,627 games,
25.3M obs) is the intermediate filtered reference. Game-level tables
`games`/`game_tags`/`game_links` were already filtered there (81.2% `games`
coverage caveat) and are reused via documented join — not duplicated here.

Machine-readable counts: regenerate with `scripts/24` and read
`data/processed/phase2-active/parquet_catalog.csv` + `validation.json` +
`extract_counts.json`. Committed copy: `docs/phase2-active/` (this catalog +
`validation.json`/`extract_counts.json`/`README.md`).

## Observed facts from the active build (2026-08-24)

- **Active size [Observed fact]:** 288,730 users / 24,509,788 observations on population games. Before degenerate exclusion: 289,397 users / 24,558,361 ratings at t=10 (matches `reports/user_population_thresholds.*` exactly); strict exclusion removes 667 users / 48,573 obs (0.31% at n≥20, 0.19% of filtered obs). Shares: 96.74% of filtered obs retained, 52.98% of filtered users; 91.03% of full-snapshot obs.
- **`degenerate_broad` preserved [Observed fact]:** 3,993 broad users total (recomputed; 3,992 in committed table, rounding); 3,326 remain in active (`is_degenerate_broad` column for sensitivity). All 667 strict users are also broad by definition.
- **16,564 of 16,567 filtered-rated games have ≥1 active rating [Observed fact]:** 3 games lost (0.02%) — essentially none at coarse granularity; 60 population games remain absent from the SQLite snapshot (recent releases), unchanged from filtered.
- **Validations passed:** 0 game_id outside 16,627; 0 users with cnt_filtered<10; 0 degenerate_strict in active; 0 strict observations in active; 0 active users missing from `users.parquet`; repeated user-game pairs preserved (1,435 pairs / 2,962 obs, max 4).
- **Flag definitions validated:** recomputed degenerate flags (ROUND-binned 1..10; SD/range on raw floats) give 667 strict / 3,993 broad, matching `reports/anomalous_rater_audit/audit_summary.json` + `removal_sensitivity.csv` (667 / 3,992).
- Game-level tables (`games` 81.2% coverage) and timestamp caveats (`postdate`/`rating_tstamp` unresolved) carry over unchanged from filtered catalog.

## Reproduce

```bash
python scripts/24_build_active_phase2_extracts.py \
    --input-dir data/processed/phase2 \
    --population data/processed/bgg_research_population.parquet
```

In worktrees without local base extracts, point `--input-dir` at the copied extracts
(e.g. `scratch/phase2`); see `data/processed/phase2-active/README.md` (and
`docs/phase2-active/README.md` committed copy) for the exact invocation used for
the current outputs. `phase2-filtered` need not exist locally — game-level tables
are documented as a join to `data/processed/phase2-filtered/` when present.
